Цель работыПостроить и проинтерпретировать модель линейной регрессии, корректно оценив её качество с помощью метрик ($MAE$, $MSE$, $RMSE$, $R^2$), а также проверить выполнение основных допущений линейных моделей.2. Описание проектаВ данном проекте реализован полный цикл машинного обучения для задачи регрессии:Загрузка и предобработка признаков с использованием пайплайна, сформированного в рамках ПР-3 (ColumnTransformer, StandardScaler, OneHotEncoder).Обучение модели LinearRegression из библиотеки Scikit-learn.Оценка качества модели на тестовой выборке с детальной интерпретацией полученных ошибок в единицах целевой переменной.Анализ коэффициентов модели (model.coef_) для определения наиболее значимых признаков.Визуальный анализ остатков (residuals) для проверки модели на наличие систематических паттернов и мультиколлинеарности.3. 5. Этапы выполнения работы5.1. Подготовка данных и интеграция ПайплайнаИспользован пайплайн из ПР-3 для предотвращения утечки данных (data leakage).Разделение выборки на обучающую ($80\%$) и тестовую ($20\%$) с зафиксированным random_state=42.Числовые признаки прошли обязательную стандартизацию (StandardScaler), что позволяет корректно сравнивать коэффициенты регрессии между собой.5.2. Обучение моделиОбучение модели линейной регрессии выполняется на обучающей выборке:Pythonmodel = LinearRegression()
model.fit(X_train_scaled, y_train)
5.3. Расчёт и интерпретация метрикОценка качества проводится строго на тестовой выборке (test):МетрикаОписаниеИнтерпретацияMAEСредняя абсолютная ошибкаПоказывает, на сколько в среднем ошибается модель в единицах целевой переменной.RMSEКорень из средней квадрат. ошибкиУчитывает штраф за крупные отклонения/выбросы.$R^2$Коэффициент детерминацииДоля дисперсии целевой переменной, объяснённая моделью ($R^2 \le 1$).5.4. Анализ коэффициентов моделиВыводятся значения model.coef_ для каждого признака. Признак с наибольшим по модулю коэффициентом $\vert{}w_i\vert{}$ оказывает наибольшее влияние на предсказание (при условии предварительного масштабирования признаков).5.5. График остатков (Residual Plot)Построение графика зависимости остатков ($y_{true} - y_{pred}$) от предсказанных значений ($y_{pred}$) для проверки отсутствия гетероскедастичности и систематических паттернов в ошибках.6.
